# SK Arabians

The website and Management System of SK Arabians, a purebred Arabian horse stud in Doha, Qatar.

- `public/` — the web root (upload its contents to `public_html` on cPanel)
- `app/` — controllers, views, services, core
- `lang/` — English and Arabic strings
- `database/` — migrations and reference data
- `templates/` — email templates
- `tools/preview/` — a database-free preview of the public website (fixtures, screenshots, static export)
- `docs/` — brand guidelines and the website version 3 notes

Configuration lives in `config/config.php` (not committed). See `docs/website-v3.md` for the current website design.
